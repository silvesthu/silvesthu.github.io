**Metal, From IOR to F0** 2025/12/15 # Metal $F_0$ $F_0$, also known as - Fresnel reflectance at 0 degree - Base Color in metallic workflow - Specular Color in specular workflow is commonly used in realtime rendering. Metals in particular, have strong specular reflection relies on this $F_0$,
It feels a bit uncomfortable not knowing if correct values are being used.
While there are presentations/websites providing number for various metals,
most don't provide exact references or method to calculate those.
To make things worse, sometimes numbers from different sources don't agree with each other.

Also gold (au) has its own problem as its R is beyond sRGB gamut (>1),
Some just clamp it and others are likely taking a normalization.
As far as I can tell, there are these 2 major IOR sources, so I tried to convert myself first.
The conversion process is already described at - [Sébastien Lagarde 2011](https://seblagarde.wordpress.com/2011/08/17/feeding-a-physical-based-lighting-mode/), also code sample "SL-GetSpecularColor" is provided - [Naty Hoffman 2020 p179](https://blog.selfshadow.com/publications/s2020-shading-course/hoffman/s2020_pbs_hoffman_slides.pdf) I use python lib [colour-science](https://www.colour-science.org/) to find if I could get same result matches any of above.
The Jupiter notebook can be found [here](https://github.com/silvesthu/JupyterPlayground/blob/master/ColorScience/IOR_to_Reflectance.ipynb).
![](1.png) Conversion process diagram from [Naty Hoffman 2020](https://blog.selfshadow.com/publications/s2020-shading-course/hoffman/s2020_pbs_hoffman_slides.pdf).
Note it assume ACEScg color space with D60,
while I'm using sRGB color space with D65 to match other references as possible.
